# Contributing to Quest Bot

Contributing to Quest Bot requires basic knowledge of TypeScript, Discord.JS and Prisma.

When committing code you take *full* responsibility for what you are committing.

## Pull requests

Please submit pull requests to a new branch.

Make sure to *test* the code you wrote *before* creating a pull request.


Use [conventional commit messages](https://www.conventionalcommits.org/en/v1.0.0/) for all commits.

## Questions

We answer all questions in our [Discord Server](https://discord.vantern.org/) or in Github.

> [!TIP]
> We respond faster in our Discord!

## AI Rules

Please refrain from using AI to create new features entirely.

Using AI to help you *understand* how to make or write something is fine but you can't have it write code or make features for you. (This is especially important for HackClub events.)

You are allowed to use AI to help *draft* a feature.
